## Definition

An element is a group of all [[Atom]]s with the same number of [[toolbox file/Notes/Chemistry/General Chemistry/01 Foundations/01.2 Atomic Theory/Proton]]s.
The term chemical element is used to describe a pure [[Substance]], consisting of a single element.
