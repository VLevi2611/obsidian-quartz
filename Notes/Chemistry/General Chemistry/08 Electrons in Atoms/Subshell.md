## Definition

All [[Atomic Orbital|Atomic Orbitals]] with the same $n$ and $\ell$ values are in the same **subshell**. The number of subshells in a [[Principal Electronic Shell]] is the same as the number of allowed values of $\ell$. For example, in the first principal shell, with $n = 1$, the only allowed value of $\ell$ is 0, and there is a single subshell. The name given to a subshell, regardless of the principal shell in which it is found, depends on the value of $\ell$. The first 4 subshells are:
1. **s subshell** $\ell = 0$
2. **p subshell** $\ell = 1$
3. **d subshell** $\ell = 2$
4. **f subshell** $\ell = 3$
The number of orbitals in a subshell is the same number of allowed values of $m_{\ell}$ for the particular value of $\ell$.
