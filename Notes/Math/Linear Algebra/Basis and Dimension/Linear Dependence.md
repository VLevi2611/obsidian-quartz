## Definition

A [[Set]] of [[Vector]]s are linear dependent if one vector can be written as a [[Linear Combination]] of the other vectors. It means that a non trivial set of vectors yields the [[Zero Vector]].
$$(4,10),(2,4),(1,3)$$
This set is linear dependent because $1 \times (2,4) + 2 \times (1,3) = (4,10)$
