## Definition

Unlike [[Linear Dependence]], A [[Set]] of [[Vector]]s are linear independent if the only way to get the [[Zero Vector]] is by setting all [[Scalar]]s in the [[Linear Combination]] to 0.

$$(1,2),(1,1)$$
This is a linear independent set of vectors because we cant create a linear combination of them to get the zero vector.
