## Definition

A **function** from a [[Set]] $X$ to a set $Y$ assigns to each [[Element Of]] $X$ exactly one element of $Y$. The set $X$ is called the [[Domain]] of the function and the set $Y$ is called the [[Codo]] of the function.
Essentially, a function takes an **input** $x$ and transforms it to an **output** $f(x)$.
$$f : X \rightarrow Y$$ 
An example of a function is $f(x) = x^2 -3$.
