## Definition

A **linear system of equations** is a list of equations where each variable is [[Multiplication|Multiplied]] by a [[Scalar]], and the scaled variables are summed.
for example:
$$
\begin{cases}
3x + 2y - z = 1 \\
2x - 2y + 4z = -2 \\
-x + \tfrac{1}{2}y - z = 0
\end{cases}
$$
